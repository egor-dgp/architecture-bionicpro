### Задача 2. Улучшите безопасность существующего приложения, заменив Code Grant на PKCE. 

#### PKCE
- Клиент Keycloak `reports-frontend` (realm `reports-realm`):
    - Standard Flow Enabled = ON
    - PKCE Code Challenge Method = S256
- Фронтенд:
    - `ReactKeycloakProvider` инициализируется с `pkceMethod: 'S256'`.

#### Проверка, что PKCE реально работает
- Подними окружение (docker-compose up --build). 
- В браузере залогинься через фронт. 
- В DevTools → Network:
  - В POST на /realms/reports-realm/protocol/openid-connect/token:
    - параметр code_verifier в теле запроса.
